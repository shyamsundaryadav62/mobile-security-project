
AppSec AI Simulator – Mobile Security Dashboard

An advanced Mobile Application Security Simulation Dashboard built using Python and Streamlit.
This project demonstrates real-world Application Security (AppSec) and SOC (Security Operations Center) concepts through an interactive interface.

🚀 Features
📊 Risk Analysis Dashboard (Basic + Detailed)
🔐 Encryption & Decryption (Fernet - AES)
🕒 Multi-Factor Authentication (TOTP)
🌐 HTTPS Security Checker
🧠 AI-Based Threat Detection (Simulation)
🔒 Permissions Audit System
📡 Network Traffic Monitoring (Simulated)
🧬 Malware Scan (Simulation)
🧮 Key Management & Hashing
🧰 Session Handling with Expiry
🧩 Code Obfuscation Demo
📜 Real-Time Audit Logging

🛠️ Tech Stack:- 
Language: Python
Framework: Streamlit
Libraries:
cryptography (Fernet)
pyotp (MFA)
pandas
requests
hashlib, base64
qrcode (optional)

🧠 How It Works

This project is a simulation-based security dashboard that mimics real-world mobile security operations:

Generates risk scores based on selected vulnerabilities
Uses Fernet encryption for secure data handling
Implements TOTP-based MFA like authenticator apps
Simulates AI threat detection & network monitoring
Tracks user actions using an audit logging system

🎯 Use Cases
Learning Application Security (AppSec)
Practicing SOC Analyst concepts
Demonstrating cybersecurity skills in projects
Resume & placement-ready cybersecurity project

⚠️ Disclaimer
This project is built for educational and simulation purposes only.
